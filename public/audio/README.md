# Sprachaufnahmen

Hierher kommen die eingesprochenen Sätze.

- Dateiname = ID des Satzes, z. B. `s03-erdbeeren.mp3`
- Die vollständige Liste steht in [`../../SPRECHTEXTE.md`](../../SPRECHTEXTE.md)
- Erlaubt sind `.mp3`, `.m4a`, `.wav`, `.ogg`, `.webm` und `.aac`

`manifest.json` wird beim Bauen automatisch erzeugt — nicht von Hand ändern.

Solange hier nichts liegt, liest die deutsche Stimme des Geräts vor. Es können
auch nur einzelne Sätze aufgenommen werden; der Rest bleibt bei der Gerätestimme.
